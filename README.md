# Numerasa

**Eksplorasi Numerasi dalam Kehidupan Sehari-hari**

## Deskripsi Proyek

Numerasa merupakan program berbasis Python yang dirancang untuk membantu siswa SMP melatih kemampuan numerasi melalui soal-soal kontekstual yang berkaitan dengan kehidupan sehari-hari.

Program ini menyediakan latihan dalam beberapa kategori, yaitu:
1. Aritmetika sehari-hari.
2. Belanja dan diskon.
3. Perbandingan.

## Tujuan

Membantu siswa memahami penerapan konsep matematika dalam situasi nyata melalui latihan soal yang sederhana dan interaktif.

## Fitur yang Direncanakan

1. Menampilkan menu kategori latihan.
2. Menghasilkan soal sesuai kategori yang dipilih.
3. Memeriksa jawaban pengguna.
4. Menghitung dan menampilkan nilai latihan.
5. Menyimpan hasil latihan ke file teks (fitur tambahan).

## Teknologi

- Bahasa pemrograman: Python
- Editor: Visual Studio Code
- Platform: Terminal/Command Prompt
